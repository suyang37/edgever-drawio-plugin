# EdgeEver Draw.io Plugin

Draw.io diagram editor embedded in EdgeEver notes.

## Install via Plugin Marketplace

Paste `https://github.com/tianma-if/edgever-drawio-plugin`

## Features
- Full draw.io editor in fullscreen panel
- Embedded diagram previews in notes
- Insert diagram as embed at cursor position
- Open/save .drawio/.xml/.svg files
